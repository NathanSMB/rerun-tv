UI mock · MVP design direction · July 2026

RERUN TV

Your library, running like it's Saturday, 1994. The chrome is a tube-black blue, panels borrow the indigo of the old cable guide channel, and everything the "broadcast" says to you — channel numbers, episode codes, timecodes — speaks in phosphor-amber mono, like a VCR's on-screen display. The recurring signature is the channel banner: it appears when you flip channels, when episodes hand off, and in the guide.

Ungroup

Select a consecutive run of episodes in any show to group it into an arc the scheduler will never interrupt.

Playback path is visible per show The DIRECT / REMUX / TRANSCODE tags come from the scan-time ffprobe, so you can see at a glance which files will cost CPU before you ever tune in.
Unmatched never blocks airing A file the parser can't read waits here for manual assignment; the rest of the show keeps scheduling normally.
Arcs are correctable The Part-N heuristic proposes groups; you can ungroup false positives or hand-group runs it missed. What's shown here is what the scheduler obeys.
